Bifrost Framework

Bifrost é um framework PHP para criar APIs com um núcleo pequeno e módulos opcionais. Você começa com o skeleton, cria suas rotas e instala somente as integrações que o projeto realmente usa.

Esta documentação é para quem vai usar o framework em uma aplicação. Ela não cobre manutenção interna do monorepo nem desenvolvimento dos pacotes.

Comece pelo skeleton

O pacote bifrost/skeleton cria a base do projeto para uma API nova.

Adicione módulos

Cache, Redis, banco, logs, filas e storage são instalados conforme a necessidade.

Modele valores

DataTypes ajudam a transformar regras de campos em tipos explícitos e reutilizáveis.

Consulte a referência

A referência lista funções públicas, parâmetros, retornos e links entre tipos.
