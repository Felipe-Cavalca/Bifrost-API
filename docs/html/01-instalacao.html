Instalação

Para criar uma aplicação nova, use o skeleton. Ele é o projeto base para quem vai consumir o framework.

Criar projeto

Crie a pasta da aplicação com o skeleton:

composer create-project bifrost/skeleton minha-api

O diretório de destino deve estar vazio ou não existir.

Instalar dependências

Entre na pasta da aplicação e instale as dependências do projeto gerado.

cd minha-api
composer install

Dependências de desenvolvimento

Em ambiente local, dependências de teste e qualidade podem aparecer em vendor/. Isso é normal. Em produção, instale sem dependências de desenvolvimento.

composer install --no-dev --optimize-autoloader

Extensões opcionais

O projeto inicial instala somente o framework. Cache, banco, filas, logs, storage e DataTypes são módulos independentes: instale apenas os pacotes exigidos pela aplicação.

Consulte Módulos opcionais para escolher o pacote adequado. Pacotes de infraestrutura podem exigir configuração no .env e um overlay do Docker Compose.
