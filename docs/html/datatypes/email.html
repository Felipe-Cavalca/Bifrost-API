Email

Valida e normaliza e-mails para minúsculas.

Instalar

composer require bifrost/datatype-email

Usar

use Bifrost\DataTypes\Email;

$email = Email::from('TEAM@BIFROST.DEV');
$email->value(); // team@bifrost.dev
