Filas

Use filas quando uma tarefa não precisa bloquear a resposta HTTP, como envio de e-mail, processamento assíncrono ou integração lenta.

Pacote disponível

composer require bifrost/queue-redis

O pacote usa Redis como backend. Se outra parte da aplicação também usa Redis com a mesma configuração, a conexão deve ser reutilizada pelo pacote base.

Quando usar

  • Operações demoradas que podem rodar depois.
  • Integrações externas que não precisam responder na hora.
  • Processamento que pode ser repetido em caso de falha.
