Módulos

Logs

Logs são opcionais e devem combinar com a infraestrutura. Nem todo projeto precisa de MongoDB só para registrar eventos.

Opções

PacoteQuando usar
bifrost/log-stdoutContainers e plataformas que coletam stdout/stderr.
bifrost/log-fileAmbientes simples com arquivo local.
bifrost/log-mongodbQuando a infraestrutura já usa MongoDB para observabilidade.

Recomendação

Para Docker, comece com stdout. Use arquivo ou MongoDB apenas quando houver motivo operacional claro.

composer require bifrost/log-stdout
