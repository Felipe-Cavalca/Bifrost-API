Primeiros passos

Depois de criar o projeto, o fluxo normal é entrar no backend, rodar a API e criar o primeiro controller.

1. Entre na aplicação

O skeleton cria o backend dentro de api/. Esse é o diretório onde você executa Composer e comandos da API.

cd minha-api/api

2. Suba o servidor local

Para um teste simples, o servidor embutido do PHP já permite validar uma rota HTTP.

php -S 0.0.0.0:8000 -t public public/index.php

3. Crie um controller

Controllers recebem uma Request e devolvem uma Response. Mantenha cada controller focado em uma intenção clara.

<?php

namespace App\Http\Controller;

use Bifrost\Framework\Attributes\Method;
use Bifrost\Framework\Http\Request;
use Bifrost\Framework\Http\Response;

final class HelloController
{
    #[Method('GET')]
    public static function show(Request $request): Response
    {
        return Response::json(['message' => 'Olá, Bifrost']);
    }
}

4. Use a rota convencional

Actions públicas seguem a convenção /controller/action. O método HelloController::show() responde em /hello/show sem cadastro manual. Use #[Method('GET')] para restringir os métodos HTTP aceitos. Quando precisar de um alias ou de uma URL diferente, registre-a em app/Http/HttpRoutes.php usando a Application.

5. Teste a resposta

curl http://localhost:8000/hello/show
