Bifrost\Framework\Contracts\Responseable

Contrato para objetos que podem ser retornados diretamente por controllers. A implementacao deve expor somente os dados seguros para a resposta HTTP. O framework serializa o retorno como JSON sem inspecionar propriedades internas do objeto.
