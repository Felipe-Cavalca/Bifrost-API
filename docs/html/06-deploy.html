Docker e deploy

Em produção, trate o app como uma aplicação Composer comum: instale dependências, configure variáveis de ambiente e exponha o diretório público.

Instalação de produção

composer install --no-dev --optimize-autoloader

Overlays do Docker Compose

Os arquivos em core/compose/ complementam o docker-compose.yml principal. Não copie e cole o conteúdo: informe cada overlay com -f. O Docker Compose aplica os arquivos na ordem recebida.

docker compose -f docker-compose.yml -f core/compose/redis.yml up --build

Logs

Para containers, prefira logs em stdout/stderr. Isso facilita coleta por Docker, Kubernetes ou ferramentas da plataforma.

composer require bifrost/log-stdout

Arquivos

Escolha o storage conforme o ambiente. Local funciona bem para desenvolvimento; S3 ou compatível é mais adequado quando a aplicação roda distribuída.

Checklist

  • Instalar dependências sem --dev.
  • Configurar secrets fora do repositório.
  • Validar healthcheck.
  • Escolher módulos de infraestrutura adequados ao ambiente.
  • Confirmar que logs e request-id estão chegando na ferramenta de observabilidade e compartilham o mesmo identificador quando o cliente envia X-Request-Id.
