Módulos

Redis

O pacote Redis existe para centralizar conexão e configuração usadas por outros módulos, como cache e filas.

Quando instalar diretamente

Normalmente você instala bifrost/cache-redis ou bifrost/queue-redis, e o Composer traz o Redis base quando necessário. Instale bifrost/redis diretamente se sua aplicação for usar a conexão Redis em código próprio.

composer require bifrost/redis

Reutilização

Configurações equivalentes devem compartilhar a mesma conexão. Isso evita que cache e fila abram conexões duplicadas para o mesmo Redis.

Se no futuro você usar cluster, sentinel ou outro cliente, a troca deve acontecer no pacote Redis, sem espalhar detalhes nos módulos consumidores.
