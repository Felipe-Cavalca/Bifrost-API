Cache

Use cache para evitar recalcular ou recarregar dados que podem ser reaproveitados por um período curto.

Opções

PacoteUso indicado
bifrost/cache-apcuCache local, simples, no próprio processo PHP.
bifrost/cache-redisCache compartilhado entre instâncias da aplicação.

Instalar

composer require bifrost/cache-redis

Quando usar TTL

Defina TTL quando o dado pode ficar desatualizado. Para dados sensíveis ou altamente dinâmicos, prefira buscar a fonte real.

Funções disponíveis

O cache é exposto pelo contrato CacheStore. As implementações APCu e Redis seguem os mesmos métodos.

MétodoUsoReferência
get(string $key): mixedRecupera um valor ou retorna null quando a chave não existe.CacheStore::get
set(string $key, mixed $value, ?int $ttlSeconds = null): voidArmazena um valor, com TTL opcional em segundos.CacheStore::set
delete(string $key): voidRemove uma chave do cache.CacheStore::delete

Implementações: ApcuCache e RedisCache.
