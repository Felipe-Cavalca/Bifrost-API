Criar um projeto novo

O sistema pode ter frontend, banco, app mobile e outros modulos. O backend PHP fica dentro da pasta api/.

1. Pasta

Crie api/ na raiz do sistema.

2. Skeleton

Instale bifrost/skeleton dentro dela.

3. Rodar

Suba Docker e acesse /health.

mkdir api
cd api
composer create-project bifrost/skeleton .
cp .env.example .env
docker compose up --build
curl http://localhost:8080/health
