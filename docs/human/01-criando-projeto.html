Comece pelo skeleton

Criar um backend do zero.

A aplicacao PHP fica em api/. O skeleton instala apenas o core, com rotas, controller de health check e Docker prontos.

mkdir api
cd api
composer create-project bifrost/skeleton .
cp .env.example .env
docker compose up --build
curl http://localhost:8080/health

1. Pasta

Crie api/ dentro do sistema consumidor.

2. Skeleton

Instale bifrost/skeleton dentro de api/.

3. Extensoes

Adicione pacotes opcionais apenas quando precisar.
