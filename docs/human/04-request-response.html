Usando o framework

Request e response

A Request concentra os dados de entrada. A Response concentra o que será enviado ao cliente.

Lendo dados da request

Use métodos de Request para acessar body, query string, headers, método e caminho.

$email = $request->input('email');
$page = $request->query('page', 1);
$requestId = $request->header('X-Request-Id');

Referências: Request::input(), Request::query() e Request::header().

Retornando JSON

APIs normalmente retornam JSON. Use Response::json() para evitar repetir headers e serialização.

return Response::json([
    'id' => $userId,
    'status' => 'created',
], 201);

Erros previsíveis

Quando precisar interromper a request com um status HTTP, use HttpException para manter o formato de erro consistente.

throw new HttpException(404, 'Registro não encontrado.');

Request ID

O framework propaga X-Request-Id. Esse identificador ajuda a cruzar logs e respostas sem expor dados sensíveis.
