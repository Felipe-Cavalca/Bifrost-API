Primeiros passos

Depois de criar o projeto, o fluxo normal é instalar dependências, rodar a API e criar a primeira rota.

1. Entre na aplicação

O skeleton cria a aplicação dentro de api/. Esse é o diretório onde você executa Composer e comandos da API.

cd minha-api/api
composer install

2. Suba o servidor local

Para um teste simples, o servidor embutido do PHP já permite validar uma rota HTTP.

php -S 0.0.0.0:8000 -t public

3. Crie um controller

Controllers recebem uma Request e devolvem uma Response. Mantenha cada controller focado em uma intenção clara.

<?php

namespace App\Http\Controller;

use Bifrost\Framework\Http\Request;
use Bifrost\Framework\Http\Response;

final class HelloController
{
    public static function show(Request $request): Response
    {
        return Response::json(['message' => 'Olá, Bifrost']);
    }
}

4. Registre a rota

No skeleton, rotas ficam em core/routes/api.php e são registradas na Application. Para uma rota GET, use Application::get().

$app->get('/hello', [HelloController::class, 'show']);

5. Teste a resposta

curl http://localhost:8000/hello
