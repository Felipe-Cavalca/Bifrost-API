Framework Composer para APIs

Construa backends pequenos, modulares e previsiveis.

O Bifrost separa o core HTTP das integracoes opcionais. Projetos novos comecam pelo skeleton e adicionam cache, fila, banco, storage e logs somente quando precisam.

Criar projeto Ver modulos 
mkdir api
cd api
composer create-project bifrost/skeleton .
cp .env.example .env
docker compose up --build
curl http://localhost:8080/health
