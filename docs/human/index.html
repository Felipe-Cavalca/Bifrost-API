Bifrost novo

Framework Composer para criar APIs do zero.

Esta documentacao mostra como iniciar um backend em api/, escolher modulos opcionais e usar attributes, DataTypes, rotas, controllers e Docker. 

mkdir api
cd api
composer create-project bifrost/skeleton .
cp .env.example .env
docker compose up --build
