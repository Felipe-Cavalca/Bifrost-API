Docker e deploy

O skeleton sobe sem infraestrutura externa. Overlays adicionam Redis, banco ou extensoes PHP conforme os pacotes instalados.

docker compose up --build
docker compose -f docker-compose.yml -f compose/redis.yml up --build
docker compose -f docker-compose.yml -f compose/postgresql.yml up --build
