Attributes e DataTypes

Attributes descrevem o contrato HTTP. DataTypes carregam validacao e valor tipado.

Method

Garante o verbo HTTP esperado.

RequiredFields

Valida corpo obrigatorio.

DataTypes

Ex.: Email, Cpf, Uuid.

#[Method('POST')]
#[RequiredFields([
    'email' => Email::class,
    'cpf' => Cpf::class,
])]
public function store(Request $request): Response
