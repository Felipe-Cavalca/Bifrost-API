Attributes e DataTypes

Attributes validam o contrato HTTP e podem executar hooks antes/depois da action. DataTypes carregam validacao reutilizavel.

Validacao

RequiredFields, OptionalFields, RequiredParams e OptionalParams.

Hooks

Cache pode reutilizar responses; Transaction controla commit/rollback.

Tipos

Email, Uuid, Cpf, Cnpj, arquivos, URLs e JSON.

#[Method('POST')]
#[RequiredFields(['email' => Email::class])]
#[Transaction]
public static function store(Request $request): Response
{
    return Response::created(['status' => 'ok']);
}
