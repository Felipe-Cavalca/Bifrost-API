DataTypes

DataTypes agora são modulares. Você instala apenas o tipo que sua aplicação usa, sem trazer todos os outros para o projeto.

Instalação recomendada

Instale o pacote específico do tipo. O Composer traz o pacote base automaticamente quando necessário.

composer require bifrost/datatype-email

Se quiser todos os tipos mantidos pelo Bifrost, use o pacote agregador:

composer require bifrost/datatypes

Pacote base

bifrost/datatype-core contém a base comum, incluindo AbstractDataType. Normalmente você não precisa instalar esse pacote manualmente, porque os DataTypes específicos já dependem dele.

Persistência

DataTypes baseados em AbstractDataType implementam Insertable. Isso permite salvar o valor no banco sem perder tipagem na aplicação.

$database->insert('users', [
    'email' => Email::from('dev@example.com'),
]);

Retorno HTTP

DataTypes baseados em AbstractDataType também implementam Responseable. Quando fizer sentido retornar somente esse valor, o controller pode devolver o DataType diretamente.

return Uuid::from('11a9d0a2-6901-4abc-85f9-6c5f985c5981');
