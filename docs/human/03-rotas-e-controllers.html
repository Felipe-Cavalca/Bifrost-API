Rotas e controllers

Rotas conectam uma URL a uma ação. Controllers executam essa ação e retornam um objeto Response.

Controller simples

Um controller deve ser pequeno. Extraia regra de negócio para services quando a lógica crescer.

final class HealthController
{
    public static function show(Request $request): Response
    {
        return Response::json(['status' => 'ok']);
    }
}

Validação de campos

Use attributes para declarar quais campos ou parâmetros são esperados pela rota.

#[RequiredFields(['email', 'name'])]
final class CreateUserController
{
    public static function handle(Request $request): Response
    {
        return Response::json(['created' => true], 201);
    }
}

Boas práticas

  • Use nomes claros, como CreateUserController ou ListOrdersController.
  • Converta dados brutos da request antes de chamar regras de negócio.
  • Retorne sempre Response, evitando saída direta com echo.
  • Não coloque acesso direto a serviços externos dentro da regra de domínio.
