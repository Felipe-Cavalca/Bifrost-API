Usando o framework

Rotas e controllers

Rotas conectam uma URL a uma ação. Controllers executam essa ação e retornam um objeto Response ou um objeto de domínio que implemente Responseable.

Controller simples

Um controller recebe Request quando precisa ler dados da chamada e retorna Response para enviar o resultado.

final class HealthController
{
    public static function show(Request $request): Response
    {
        return Response::json(['status' => 'ok']);
    }
}

Registro de rota

Use os atalhos da Application, como get(), post(), put(), patch() e delete().

$app->get('/health', [HealthController::class, 'show']);

Validação de campos

Use attributes como RequiredFields para declarar quais campos ou parâmetros são esperados pela rota.

#[RequiredFields(['email', 'name'])]
final class CreateUserController
{
    public static function handle(Request $request): Response
    {
        return Response::json(['created' => true], 201);
    }
}

Boas práticas

  • Use nomes claros, como CreateUserController ou ListOrdersController.
  • Converta dados brutos da request antes de chamar regras de negócio.
  • Retorne Response ou Responseable, evitando saída direta com echo.
  • Consulte a referência pública quando quiser ver parâmetros e retornos.
