FilePath

Valida caminhos relativos de arquivo. O pacote instala automaticamente os tipos de nome de arquivo e pasta.

composer require bifrost/datatype-file-path
use Bifrost\DataTypes\Filesystem\FilePath;

$path = FilePath::from('avatars/user.png');
